# Installing the extension

Download the files

1. Open Chrome Extensions Page: Go to chrome://extensions/ in your browser. 

2. Enable Developer Mode: Toggle on the "Developer mode" switch in the top right corner. 

3. Load Unpacked Extension: Click the "Load unpacked" button and navigate to the folder containing your extension's files. 

4. Confirm and Install: The extension should now be installed and visible on your browser's extensions page.
